설치 가이드

구글 시트와 연결하면 체크가 시트에 바로 저장됩니다. 시트를 연결하지 않아도 앱은 시연 모드로 모두 동작합니다.

1시트에서 Apps Script 열기

구글 시트 26년 11월 자체 실행반을 열고, 메뉴에서 확장 프로그램 → Apps Script를 누릅니다.

편집기가 열리면 왼쪽 Code.gs 안의 기본 내용을 모두 지웁니다.

아래 전체 복사를 눌러 Code.gs에 붙여넣고 저장(Ctrl+S / ⌘+S)합니다.

코드 전문: apps-script/Code.gs

3웹 앱으로 배포

  1. 오른쪽 위 배포 → 새 배포
  2. 유형 선택(톱니) → 웹 앱
  3. 다음 사용자로 실행: 나
  4. 액세스 권한: 모든 사용자
  5. 배포 → 권한 승인 → 나오는 웹 앱 URL 복사
URL은 …/exec로 끝나는 것을 쓰세요. …/dev 주소는 만든 사람만 열 수 있어 실행반 앱이 연결되지 않습니다. 코드를 고친 뒤에는 배포 관리 → 수정 → 새 버전으로 다시 배포해야 반영됩니다.

4앱에 URL 연결

실행반 앱으로 돌아와 오른쪽 위 ⚙ 설정 → Apps Script 웹앱 URL에 붙여넣고 저장. 연결 테스트가 성공하면 상단 배너가 초록색 시트와 연결됨으로 바뀝니다. 이제 체크·목표 수정·참여자 추가·다음 달 이월이 모두 시트에 기록됩니다.

앱이 하는 일

동작시트에서 일어나는 일
주차 동그라미 탭해당 주차 칸의 체크박스를 켜고 끕니다. 달성률 수식이 자동 계산됩니다.
목표 수정목표 내용(달성 가능한 목표 칸)과 총 목표 횟수만 바꿉니다.
다음 달도 참여연장여부 칸을 켜고 끕니다.
참여자 추가맨 아래에 새 행을 만들고 달성률 수식·체크박스를 붙입니다.
다음 달 이월연장여부가 켜진 사람만 26년 12월 탭으로 옮깁니다. 그 달 탭이 없으면 새로 만들고, 지난 달 데이터는 그대로 둡니다.
이미 있는 셀의 값과 수식은 덮어쓰지 않습니다. 쓰기는 앱이 실제로 누른 그 칸에만 일어납니다.

문제가 생기면

  • 연결 실패: 액세스 권한이 모든 사용자인지, URL이 /exec인지 확인하세요.
  • 배포 후 코드 수정: 저장만 하면 반영되지 않습니다. 새 버전으로 다시 배포하세요.
  • 다른 시트에 붙일 때: 독립 스크립트로 만들었다면 CONFIG.SPREADSHEET_ID에 시트 ID를 넣습니다.
  • API 직접 호출: …/exec?action=ping, ?action=get&month=26년 11월 처럼 GET으로 확인할 수 있습니다. 응답은 JSON(또는 callback=을 주면 JSONP)입니다.
